# Assessment 3 - Where Should the Wellbeing Budget Go?

Tests four proposed burnout interventions (ergonomic stipend, mental-health support,
workload caps, connection programme) against the Remote Work & Health Impact Survey 2025.

1. Put `post_pandemic_remote_work_health_impact_2025.csv` (from Kaggle) in this folder.
2. Install: `pip install pandas numpy scipy statsmodels scikit-learn matplotlib seaborn jupyter`
3. Open `remote_work_burnout_analysis.ipynb` and run Kernel -> Restart & Run All.

Outputs in `outputs/`: cleaned CSV, report figures (fig1-3), appendix figures (figB1-B2),
and `key_results.json` with every number quoted in the report.
`remote_work_burnout_analysis.html` is the executed notebook, readable without Python.
